# Hi, I'm Lázaro

I lead the AI area at TradeSpark, an Argentine capital-markets fintech, where I build tools for problems traders and financial analysts run into every day. I try to bring in AI only where it's actually worth it.

I'm a Systems Engineer (UNICEN, Argentina). I started at TradeSpark as an ML engineering intern, building a pipeline to predict stock returns from market data. Before that I spent two years as a teaching assistant at UNICEN, and before university I was already taking Platzi courses, which is still where I go when curiosity beats the syllabus.

## Some things I've built

- **[CEApp](https://red-cea.web.app)**: a multi-tenant platform for Agricultural Training Centers. Each center gets its own public site, and one admin panel handles enrollments, the lifecycle of each training, and the data exports government agencies ask for. In production at [ceabragado.com](https://ceabragado.com) and [ceadiecinueve.com](https://ceadiecinueve.com).
- **[Editor de Décimas](https://github.com/lazarovttac/decimas)**: I got hooked on writing décimas after watching Jorge Drexler's talk about them, and a normal text editor doesn't tell you how many syllables a verse has or what it has to rhyme with. This one does. I built it with Claude Fable 5 from a single prompt.
- **[My Automata](https://my-automata.web.app)**: an editor for drawing finite automata (DFA/NFA) and testing which strings they accept.
- **[GuessTheClip](https://guesstheclip.com)**: guess a YouTube creator's video from an audio clip that keeps getting longer.
- **[Semillero](https://semillero-personas.web.app)**: a job portal for an HR team, with CV upload and a backoffice for their listings.
- **Mobile games** made in Unity: Donut Tunnel, Neon Hover and Planet Dance were on Google Play until my developer account was closed for low activity. My first one, A-void, is gone for good: I didn't know GitHub existed yet and lost the source files.

Most of what I build these days uses Python (TensorFlow/Keras, Pandas) or React with Firebase.
